# SunoFlix

Curated, validated SUNO V6 style prompts for film and television scoring.

## Contents

- `prompts/documentary/investigative-series-suno-v6.md`: twelve instrumental cues for a premium investigative / true-crime / manhunt documentary series, covering cold open through unresolved end credits. Each prompt is at most 1000 characters, has no lyrics or artist references, and is written to sit beneath narration and interviews.

## Prompt conventions

- One continuous style prompt per cue, in English, at most 1000 characters including spaces.
- Concrete musical instructions (tempo, meter, tonal centre, instrumentation, arrangement arc, mix character) instead of generic adjectives.
- Explicit exclusions at the end of each prompt.
- No composer, artist or song references.
